# 应用图标

图标为 reicon 的 `discover-filled`（https://yesicon.app/reicon/discover-filled），黑色 glyph 居中、直径约 56% 边长，底色 `#C8D1D9`，与 Android / iOS 图标同一稿。

- `TokiDiscover.ico`：exe 图标（csproj `ApplicationIcon`），含 16–256 七档尺寸。
- `StoreLogo.png` / `Square150x150Logo.png` / `Square44x44Logo.png` / `Wide310x150Logo.png` / `SplashScreen.png`：Package.appxmanifest 引用的磁贴与闪屏图。
